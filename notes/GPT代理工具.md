# cockpit

## 公告1

如果已经按照上一条公告正确设置 ChatGPT.exe 启动路径，但通过 Cockpit Tools 切号或重启 ChatGPT 后，GPT-5.6 仍未显示，可以为对应的 API Key 绑定一个 OAuth 账号。

绑定方法：

1. 进入 Cockpit Tools 的 Codex 账号页面
2. 找到需要使用的 API Key 账号卡片或 Codex API 服务账号卡片
3. 在账号卡片信息中找到「OAuth 绑定」
4. 点击右侧的「绑定」
5. 从账号列表中选择一个已添加的普通 Codex OAuth 账号
6. 完成绑定后，重新通过 Cockpit Tools 切换一次该 API Key 账号

绑定后的效果：

• ChatGPT 的启动、重启、模型显示和客户端交互与普通账号一致
• 实际对话请求仍通过该 API Key 对应的供应商发送
• Codex API 服务账号同样适用，不会改为消耗 OAuth 账号的对话额度

建议优先选择 Plus、Team 或更高套餐的 OAuth 账号进行绑定，以获得更完整、稳定的客户端功能和模型显示体验。
